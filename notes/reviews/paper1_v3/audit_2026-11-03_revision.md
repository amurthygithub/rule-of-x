## Status after the fixes

**F1: fresh-clone reproduction at 3998b33 (3 November 2026).** Script and logs in the session scratchpad (`fresh3/run.sh`, `driver.log`, `regenerate.log`, `compare.py`, `compare.json`), not in the repository.

- **Raw data.** `code/fetch_raw_data.py` downloaded the four GitHub sources over the network (189 files: aieconindex_r 82, gpts_are_gpts 23, ms_working_with_ai 11, metr_eval_analysis 73), all verified against `data/raw/CHECKSUMS.sha256`. The other hosts refused scripted downloads (huggingface.co, bls.gov, onetcenter.org, stern.nyu.edu; HTTP 403 at the session's proxy), so their files were placed with `--from-dir` from copies of the files as used, verified the same way; `--check` then passed. - **Run.** All 18 stages through `latex_p1` completed in 38 minutes on 2 cores (the bootstraps included); stage `latex_p2` stops by design because Paper 2 has no main document yet.
- **Comparison with the commit** (git status after the run, then text and rendered pixels for PDFs; `compare.py`). 9 tracked files differed; nothing else (every data file, table, macro file and the plain abstract identical):
  1. `notes/playbook_results.json`: run time and generation time only (expected).
  2. `notes/verify_theory_output.txt`: the script path in one warning (expected), and the committed file was stale: it held the 2 November wording of checks 29b and 29d, which were changed on 3 November to derive their expected values. Regenerated.
  3. `notes/backtest_results.json`: the committed file recorded the hash of the engine defaults before the sync of 3 November; the backtest's results were unchanged. Regenerated.
  4. `figures/fig_stress.pdf`, `fig_empirical_frontier.pdf`, `fig_scale.pdf`, `fig_scores_time.pdf`: same text, same data, layout shifted by under a point (for example the left axes of the stress figure 190.65 against 189.70 points wide). Cause: the Python environment, not the code or the inputs. The same script on the same inputs gives the committed bytes under the session's system Python, which carries two installs of matplotlib and many unrelated packages, and the fresh-clone bytes under the clean environment. The last three figures are not used by either paper.
  5. `paper1/paper1.pdf`: text identical and every page pixel-identical (creation date only).
  6. `paper1/supplement.pdf`: one page differs, page 60, the stress figure of item 4.
